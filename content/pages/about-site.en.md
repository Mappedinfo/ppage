# About This Site

This site is built with **PPage**, a pure frontend personal homepage generation system.

## Key Features

- 🚀 **Pure Frontend Architecture** - Built with React + Vite, no backend server required
- 📝 **Markdown-Driven** - Support Markdown content creation with automatic parsing and rendering
- 🎨 **Multiple Themes** - Built-in Light, Dark, and Academic themes
- 🌍 **Internationalization** - Support Chinese/English switching with configurable content
- ⚙️ **Configuration-Driven** - Quick customization through YAML configuration files
- 📦 **Auto-Discovery** - Automatically scan Markdown files and resource links
- 🎯 **GitHub Pages Deployment** - One-click deployment to GitHub Pages

## Tech Stack

- **Frontend Framework**: React 19
- **Build Tool**: Vite
- **Markdown Rendering**: markdown-it
- **Routing**: React Router
- **Styling**: CSS Modules
- **Deployment**: GitHub Pages

## Use Cases

- Personal homepage/resume showcase
- Academic researcher's personal website
- Blog/article publishing
- Project portfolio showcase
- File/paper sharing
